## What's different from the planner portfolio

- Role label: Frontend Developer (instead of Service Planning · PM)
- First-screen numbers: services shipped · 3 ops tools · 170+ PRs · 2.2 s vote-to-screen
- "What I do" is a stack grouped into Frontend / Backend · Data / Infra · Tools
- Selected work comes right after the stack; order is hackathon ops tools → CleanB → FlowPay → Y:Wave
- Project cards show stack chips plus GitHub and live links
- Project pages add the stack, **technical challenges (problem → solution → result)** with links to the source files, and an architecture flow diagram

Technical claims come only from code in the public repositories; the private CleanB repo is described only from [PORTFOLIO.md](PORTFOLIO.md).

## Tech Stack

Next.js 16 (App Router) · TypeScript · Tailwind CSS v4 · next-intl (ko/en) · Framer Motion

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). Set the deployed URL with `NEXT_PUBLIC_BASE_URL` (defaults to `https://dev-portfolio-phi-eight.vercel.app`).
